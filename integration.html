Intégrer la webmap dans un autre site

La webmap existe en deux versions qui pointent vers la même application : la page autonome, indexée par les moteurs de recherche, et un mode intégré allégé, pensé pour être inséré dans Sahelink et dans les sites des membres de l’IFS. Une mise à jour des données se répercute partout en même temps.

2. Options

AdresseEffet
?embed=1Mode intégré : bandeau compact, filtres repliés dans un bouton, lien « Ouvrir la carte complète ».
?embed=1#pays=MauritanieOuvre la carte déjà filtrée sur un pays (utile pour le site d’un membre actif dans un seul pays).
?embed=1#org=grdrN’affiche que les projets d’un membre et ceux qu’il co-porte.
?embed=1#theme=eau_assainissementFiltre sur une thématique.

Tous les filtres de la carte peuvent être combinés de cette façon : le bouton « Copier le lien de cette vue » de la page autonome génère l’adresse correspondante.
